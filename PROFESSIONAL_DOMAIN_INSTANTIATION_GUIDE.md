# Professional Domain Instantiation Guide

**Purpose:** prevent the shared MKUFT vocabulary from becoming semantically loose when the architecture is carried into a professional domain.

This guide does not add a new theory, equation, layer, mechanism, or evidential claim. It is a reader-interface and claim-discipline bridge. The technical owners remain the controlling scientific objects.

## The universal rule

Terms such as **state**, **relation**, **dependency**, **scale**, **closure**, **reopen**, **restore**, **address**, **context**, and **target** are role names only until they are instantiated in the receiving domain.

Before a domain-specific scientific claim is evaluated, the application must identify, prospectively where the test requires it:

1. the domain-native object being modelled;
2. the target quantity or property to be predicted, preserved, recovered, or distinguished;
3. the state variables actually retained;
4. the exact relation or dependency claimed to be decision-bearing;
5. the map, coarse-graining, embedding, quotient, intervention, ablation, or comparison used;
6. the measurement or evaluation surface on which success or failure is judged;
7. the strongest adequate domain-native baseline;
8. the stopping, refusal, null, or contraction condition.

If those replacements cannot be made without changing the role after the outcome is known, the application is undefined or fails. Shared words, graph shape, visual similarity, or repeated algebra do not supply the missing domain-native object.

A cross-domain intuition is allowed to motivate a candidate formal object. Once the candidate is defined in the target problem space, it is judged there on its mathematics, measurement, baseline and evidential burden. What does **not** transfer automatically is warrant, mechanism, causal status, authority, units, evidence, or physical meaning.

## Forward/backward registration test

Every professional example should survive both traversals.

**Forward:**

```text
generic role
→ domain-native object
→ formal operation
→ measurable/evaluable consequence
→ falsifier or null
```

**Backward:**

```text
measured/evaluated consequence
→ exact operation that produced it
→ exact relation tested
→ domain-native object
→ generic role
```

If the backward traversal lands on an undefined word such as “it”, “context”, “dependency”, “state”, “scale”, “reopen”, or “resolve”, the professional handoff is not finished.

## Physics instantiation

A physics reader should not be asked to reason from generic layer language alone.

For a declared physical application:

- **object** = the specified physical state, state space, field configuration, operator domain, ensemble, or other native physical object;
- **target** = a declared observable, transition, correlation, distribution, recovery property, or other physical quantity;
- **relation** = the exact mathematical relation claimed to affect that target;
- **scale/layer transfer** = an explicit embedding, quotient, coarse-graining, common observable, effective map, or other lawful comparison between the declared spaces;
- **remove/ablate** = neutralise, delete, scramble, substitute, or otherwise perturb the exact claimed relation while holding the comparison object fixed as far as the physics permits;
- **restore/reopen** = reinstate the smallest lower-address variable/relation set required by the declared target after the coarser description fails;
- **measurement surface** = the specified instrument/readout and its resolution, uncertainty and back-action where relevant;
- **baseline** = the strongest adequate ordinary physical model for the same target and regime.

The important boundary is simple: if no lawful comparison map exists between two physical descriptions, the comparison is **undefined**, not an interesting residual.

Likewise, a formally valid representation is allowed to exist even when it was motivated by an analogy from elsewhere. It earns physical significance only if it survives the native physical mathematics and then, where a physical claim is made, the required measurement and baseline burden.

### Minimal physics example

Suppose lower states `x` are mapped to a proposed higher description `y = pi(x)` and the target property is `q`.

The higher description is sufficient for `q` only if lower states grouped together by `pi` remain equivalent for the declared target under matched intervention/environment conditions. If two lower states with the same `y` generate materially different target futures, the higher description must reopen lower detail or remain explicitly multiscale.

That is a claim about specified objects and maps, not a semantic instruction to “change scale until it resolves”.

## Biology / neuroscience instantiation

A biology or neuroscience reader should be able to point to the exact measured objects before shared MKUFT vocabulary is used as shorthand.

Let

```math
X_t = \text{measured present biological state},
```

```math
H_t = \text{a pre-specified candidate history/internal-state variable},
```

and

```math
Y_{t+\Delta} = \text{the declared future biological readout at horizon }\Delta.
```

The strongest ordinary present-state model is compared with a model that includes the candidate missing state/history term:

```math
\hat Y_{t+\Delta}=f(X_t)
```

versus

```math
\hat Y_{t+\Delta}=g(X_t,H_t).
```

In this application:

- **state** = the explicitly measured vector or structured state `X_t`;
- **history** = the pre-specified biologically defensible variable `H_t`, not generic “memory”;
- **target** = `Y_{t+Delta}`, fixed before the outcome is inspected;
- **dependency** = the specified contribution/relation connecting the candidate variable to the declared target;
- **remove/ablate** = evaluate the same task without that variable/relation, or with a pre-specified lawful neutralisation/scramble where appropriate;
- **restore/reopen** = reintroduce the smallest biologically defensible omitted state/history variable or dependency-complete set required by the widened operation;
- **scale change** = define a new biological object — for example cell, circuit, population, tissue — together with the map between levels and the target owned at the new level. It does not mean verbally zooming outward;
- **resolve** = improve or restore the pre-declared biological criterion: held-out prediction, disappearance of an unexplained divergence, correction of a causal/connectivity inference, or another stated native measure;
- **null** = the added state/history information produces no material improvement or deformation under the frozen test, in which case the application earns nothing from that proposed addition.

The experiment should first match the measured present state as well as the native field permits, deliberately vary the candidate history/internal state, apply the same declared challenge, hold boundary/environment/readout conditions fixed as far as possible, and compare against the strongest ordinary model.

If the future difference disappears under better state matching, challenge matching, stochastic modelling, ordinary hidden-state estimation, environment control, or measurement control, the stronger MKUFT interpretation is not earned.

This is the professional meaning of “reopen”: not “look deeper until something appears”, but restore the smallest pre-declared or independently justified native variable set needed for the declared target and test the repair on fresh cases.

## AI / software / ATLD instantiation

The AI/software branch provides the most inspectable version because the dependency objects can often be named directly.

For a matched-control ATLD-style application:

- **object** = the exact task state, node, packet, artefact, subproblem, or addressed work object;
- **target** = the declared task output, evaluator score, correction, contradiction-localisation result, or other fixed performance criterion;
- **dependency** = a named typed edge or prerequisite relation between declared objects;
- **active traversal** = the allowed operation that follows and revisits those dependencies under the protocol;
- **remove** = delete, neutralise, scramble, isolate, block revisit, replay without live traversal, or counterfactually substitute the exact relation according to the pre-specified control;
- **propagation** = the measured downstream change after that intervention;
- **restore/reopen** = recover the smallest dependency-complete subgraph, provenance-bearing chain, or lower object needed to restore the declared capability;
- **scale** = a formally declared task/module/system boundary, not a loose change in narrative viewpoint;
- **baseline** = matched content and resource budgets with flat, isolated, scrambled, no-revisit, replay, or stronger ordinary architecture controls as appropriate;
- **null** = the typed relation/traversal condition does not outperform or deform differently from the strongest matched comparator.

For a claimed dependency `r`, the useful question is not “does it matter?” but:

> Under the frozen task and evaluator, does lawful removal or neutralisation of `r` produce the predicted downstream deformation, and does restoring the smallest dependency-complete structure recover it?

If not, `r` has not been shown to be load-bearing for that claim.

## What “scale” is allowed to mean

“Scale” must never function as a licence to move the goalposts.

A scale change requires a newly declared object and a lawful relation to the previous object. Depending on the field, that may be an aggregation, quotient, coarse-graining, embedding, projection, hierarchy level, module boundary, population definition, spatial resolution, temporal resolution, or another native construction.

Changing scale can therefore change the question. When it does, the new target, state, baseline and falsifier must be stated again. A failed claim at one scale is not repaired merely by moving to another.

## What “reopen” is allowed to mean

“Reopen” is not permission to restore arbitrary detail after failure.

It means that a representation previously judged sufficient for a declared use has become insufficient under a widened or changed declared operation. The repair must recover the smallest dependency-complete lower information required by that operation, using preserved provenance/descent where available, and then re-evaluate the upper closure.

If the architecture can only respond by reopening everything, or by inventing a new field after seeing the outcome, the compression/interface claim has failed.

## Stop condition for the reader carrier

The professional handoff is complete when the reader can identify, without reconstructing private development history:

- the exact domain-native object;
- the target quantity;
- the candidate relation;
- the operation or ablation;
- the measurement/evaluation surface;
- the native baseline;
- the scale/address map where one is used;
- and the result that kills, contracts, preserves, or reopens the claim.

At that point, shared vocabulary is legitimate compression. Before that point, it is not allowed to carry scientific weight by itself.

## Ownership boundary

This guide is a live GitHub reader bridge. It does not alter frozen DOI-bearing publication objects, equations, numerical results, or scientific history. Where its shorthand conflicts with a canonical technical owner, the canonical technical owner controls and this guide must be corrected.
