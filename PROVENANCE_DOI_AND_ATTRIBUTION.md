## Core rules

1. Every published object keeps its own title, author, DOI, version, citation identity, carrier identity, and licence/rights state.
2. A DOI is an identifier and provenance route, not a licence.
3. A live GitHub module or naming note is not silently the same object as a frozen DOI deposit.
4. A repository mirror or Drive copy does not acquire publication custody merely because it is convenient to read.
5. The exact object being cited or reused controls its version and rights identity.
6. Where a licence has not been verified for the exact object, do not infer one from a neighbouring publication.
7. Current paper discovery is owned by [`papers/README.md`](papers/README.md); frozen repository carriers and checksum witnesses are indexed by [`publications/README.md`](publications/README.md).
8. Carrier integrity is governed by [`RENDERING_AND_PUBLICATION_INTEGRITY.md`](RENDERING_AND_PUBLICATION_INTEGRITY.md); stable release identity is governed by [`docs/34_RESEARCH_OBJECT_IDENTITY_RELEASE_INTEGRITY_AND_REPRODUCIBILITY.md`](docs/34_RESEARCH_OBJECT_IDENTITY_RELEASE_INTEGRITY_AND_REPRODUCIBILITY.md).
9. Semantic agreement among mirrors, summaries, metadata files, or AI retrieval results is not independent provenance. Independence depends on recoverable ancestry and custody.
10. Historical wording and names remain part of the record. Later naming refinement is prospective unless a frozen publication itself used the later term.

## Live canon, publication record, frozen deposit, and mirror

Use the object appropriate to the claim:

```text
current scientific operation / latest method
→ live module or live repository synthesis

historical publication statement / citation
→ exact DOI/version object

publication identity / rights / carrier relationship
→ standalone publication record

checksum / frozen byte witness
→ publications/ identity record or exact mirror
```

A Drive file may mirror a publication or live public document, but it does not become publication custody. A live GitHub correction does not alter a frozen DOI object. A naming note does not become scientific evidence merely because it is public and timestamped.
