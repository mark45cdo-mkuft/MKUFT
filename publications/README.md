# MKUFT Publications and Frozen Mirrors

This directory is the preservation area for repository-held publication mirrors, checksum records and frozen-object identity witnesses. The direct human-reader index for papers is [`papers/README.md`](../papers/README.md).

A live module, repository paper route, reading edition, convenience mirror and DOI-bearing deposit are related objects but are **not interchangeable**. Zenodo or the exact deposited carrier retains publication custody for a frozen DOI object; live GitHub work may refine or extend the science without silently rewriting that deposit.

## Object-boundary rule

Use the exact object required by the task:

```text
live scientific question
→ live module / live repository synthesis

published citation / historical claim
→ exact DOI/version object

carrier verification
→ frozen identity/checksum record

human discovery
→ papers/README.md or INDEX.md
```

Do not infer publication status, licence, version identity, or independent evidence merely from the presence of a mirror or related live module.
