## Abstract

Scientific models can fail because a representation has grouped together states, relations, scales, histories, or properties that are equivalent for one purpose but not for the target currently being predicted, controlled, or explained. This paper formalises **Typed Decomposition-Reconstruction (TDR)** as a prospective protocol for detecting and testing such hidden scientific conflations.

TDR starts from a native representation and declared target. When materially different target futures, interventions, or closure decisions remain inside one operational address, the method decomposes only the decision-bearing object, types the resulting components and relations, forbids automatic property inheritance across unlicensed relations, reconstructs only through explicit carrier or realisation relations, subtracts native and simpler ownership, and requires the proposed repair to improve held-out or prospective discrimination.

The paper does **not** claim novelty for decomposition, abstraction, typing, causal abstraction, predictive state, sufficient representation, ablation, model selection, or hidden-state search individually. The narrower candidate is the ordered conjunction and its prospective accountability rule.

A secondary construct, **Wake**, is defined as a target-relative retained traversal/history variable: the smallest load-bearing residue of prior traversal that changes present interpretation, prediction, or admissible continuation. Wake is not a substance, universal memory law, or replacement for domain-native hysteresis.

## Existing calibrations: success without inflation

Two already-public source-programme outcomes are included as **retrospective calibrations of verdict quality**, not as prospective evidence for TDR superiority.

- **ATLD 2:** a positive diagnostic/no-coordinate-inflation case. RR-14 exposed a real branch-localisation / route-support / calibration seam, but existing ATLD 2 machinery already owned it, so a thirteenth coordinate was not justified.
- **Bell/CHSH typed boundaries:** a productive physical null. The independent Bell-local new-physics delta remained null under the tested comparator family, while a non-null typed correspondence, custody, and falsification result survived.

Scientific restraint is not implemented by flattening earned positives. TDR keeps outcome salience and evidence authority separately typed: a positive result may be stated positively at its actual scope, while a null remains null where it is null.

## Why the method is worth testing

The performance claim is deliberately unawarded, but its possible significance is not trivial. If independent teams can freeze TDR before outcome access and then use it to identify decision-bearing distinctions that strong native or generic methods miss, TDR would amount to a **transferable discovery instrument**: not a new law of nature, but a reproducible way of finding where a representation has hidden a consequential distinction.

That possibility should neither be promoted in advance nor cooled into “mere housekeeping.” It belongs under a benchmark capable of separating those outcomes.

## Target-relative hidden conflation

Let

```math
A_{\Theta}:\mathcal X\rightarrow\mathcal Z_{\Theta}
```

be a native operational address. States are equivalent at that address when

```math
x\sim_{\Theta}x'
\quad\Longleftrightarrow\quad
A_{\Theta}(x)=A_{\Theta}(x').
```

For target `q`, horizon `Δ`, intervention class `U`, environment class `E`, transition kernel `K^Δ`, and discrepancy `d_Q`, define the target-relative address residual

```math
\mathcal R_q(\Theta;U,E,\Delta)
=
\sup_{\substack{x\sim_{\Theta}x'\\u\in U,\ e\in E}}
 d_Q\!\left(
 q_*K^{\Delta}(\cdot\mid x,u,e),
 q_*K^{\Delta}(\cdot\mid x',u,e)
 \right).
```

The representation closes for the declared target when

```math
\boxed{
\mathcal R_q(\Theta;U,E,\Delta)
\leq
\varepsilon_q.
}
```

A residual above tolerance is a diagnostic trigger, not proof of one preferred hidden variable or ontology.

For a candidate coordinate `c`, let

```math
\Theta^+=\Theta\cup\{c\}
```

and define completion gain

```math
\Gamma_q(c\mid\Theta)
=
\mathcal R_q(\Theta;U,E,\Delta)
-
\mathcal R_q(\Theta^+;U,E,\Delta).
```

Retention requires protected gain plus native-owner, leakage, complexity, and simpler-state subtraction.

## Three domain mappings

The paper works the same procedural burden through physics, biology, and AI without claiming that those domains share one physical mechanism.

- **Physics:** informational adjacency and physical proximity are typed separately; any physical consequence still owes a declared coupling/realisation with native variables, units or normalisation where applicable, baseline, and falsifier.
- **Biology:** same-address cells with materially different protected futures trigger a search for native load-bearing state/history/boundary variables before any new mechanism is claimed.
- **AI evaluation:** a candidate residual coordinate with positive diagnostic gain is not automatically independent; existing direct, derived, and coalition ownership must be subtracted first.

## Wake and Wake Gap

Let available traversal history be `H_{0:t}` and a candidate retained compression be

```math
W_t=\Phi(H_{0:t}).
```

The augmented state is

```math
S_t^+=(S_t,W_t).
```

Wake earns load only when it improves the declared target beyond the simpler present-state representation. A predictive version is

```math
\Gamma_q^{W}
=
\mathcal R_q(\Theta;U,E,\Delta)
-
\mathcal R_q(\Theta\cup\{W\};U,E,\Delta).
```

A **Wake Gap** is a target-relative difference in retained traversal state that produces materially different interpretation, prediction, or lawful continuation under the same present input. If present state already closes the target, Wake returns null.

## Prospective generator test

For prospectively frozen task `q`, let `\mathcal G_{\mathrm{TDR}}` be TDR, `\mathcal B_q` the preregistered serious-comparator family, and `F_q(M)` the matched-resource portfolio score.

```math
F_{\mathrm{base}}^{*}(q)
=
\sup_{b\in\mathcal B_q}F_q(b).
```

```math
\boxed{
G_{\mathrm{gen}}(q)
=
F_q(\mathcal G_{\mathrm{TDR}})
-
F_{\mathrm{base}}^{*}(q).
}
```

Interpretation:

```text
G_gen(q) > 0  → TDR wins on that frozen task/envelope
G_gen(q) ≈ 0  → no demonstrated advantage
G_gen(q) < 0  → strongest comparator wins
```

The score must include false positives, failed branches, repairs, search cost, and revisions. It must also reward **correct positive retention and correct reduction/rejection/abstention** against protected outcomes. Correctly scoped verdict quality, not novelty count, is the benchmark object.

## Scientific status

The equations are methodological/statistical scaffolds until the task family, comparators, score, resource envelope, stopping rule, uncertainty model, and protected outcomes are frozen and run. They are not physical laws.

The broad TDR claim should reduce or fail if the method is hindsight-dependent, unstable across independent analysts, no better than native methods, complexity-inflating, unable to abstain, dependent on privileged resource advantages, or consistently null/negative under `G_gen`.

Publication establishes a frozen, citable **method object**. It does not establish TDR generator superiority.
