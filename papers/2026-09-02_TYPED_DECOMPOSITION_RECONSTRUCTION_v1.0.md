## Abstract

Scientific models can fail because a representation has grouped together states, relations, scales, histories, or properties that are equivalent for one purpose but not for the target currently being predicted, controlled, or explained. This paper formalises **Typed Decomposition-Reconstruction (TDR)** as a prospective protocol for detecting and testing such hidden scientific conflations.

TDR starts from a native representation and declared target. When materially different target futures, interventions, or closure decisions remain inside one operational address, the method decomposes only the decision-bearing object, types the resulting components and relations, forbids automatic property inheritance across unlicensed relations, reconstructs only through explicit carrier or realisation relations, subtracts native and simpler ownership, and requires the proposed repair to improve held-out or prospective discrimination.

The paper does **not** claim novelty for decomposition, abstraction, typing, causal abstraction, predictive state, sufficient representation, ablation, model selection, or hidden-state search individually. The narrower candidate is the ordered conjunction and its prospective accountability rule.

A secondary construct, **Wake**, is defined as a target-relative retained traversal/history variable: the smallest load-bearing residue of prior traversal that changes present interpretation, prediction, or admissible continuation. Wake is not a substance, universal memory law, or replacement for domain-native hysteresis.

## Prospective generator test

For prospectively frozen task `q`, let `\mathcal G_{\mathrm{TDR}}` be TDR, `\mathcal B_q` the preregistered serious-comparator family, and `F_q(M)` the matched-resource portfolio score.

```math
F_{\mathrm{base}}^{*}(q)
=
\sup_{b\in\mathcal B_q}F_q(b).
```

```math
\boxed{
G_{\mathrm{gen}}(q)
=
F_q(\mathcal G_{\mathrm{TDR}})
-
F_{\mathrm{base}}^{*}(q).
}
```

Interpretation:

```text
G_gen(q) > 0  → TDR wins on that frozen task/envelope
G_gen(q) ≈ 0  → no demonstrated advantage
G_gen(q) < 0  → strongest comparator wins
```

The score must include false positives, failed branches, repairs, search cost, and revisions. It must also reward **correct positive retention and correct reduction/rejection/abstention** against protected outcomes. Correctly scoped verdict quality, not novelty count, is the benchmark object.
