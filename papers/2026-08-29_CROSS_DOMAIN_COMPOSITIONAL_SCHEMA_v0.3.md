## Abstracted result

Version 0.3 formalises a typed cross-domain compositional schema for deciding when a compressed or closed lower object may be reused in a wider composition without silently losing a relation that later becomes decision-bearing.

Let the fuller relational object be

```math
X=(N,R,\tau,\alpha),
```

where `N` is the bounded constituent family, `R` the typed relation family, `\tau` the type/address/scope assignment, and `\alpha` only those auxiliary coordinates that are operationally real in the target domain. For a declared future-operation family `F`, a closure is

```math
Y=C_F(X).
```

Evaluation is typed as

```math
\operatorname{Eval}_k(X)
=
\bigl(s_k(X),v_k(X),\rho_k(X)\bigr),
```

so a comparison can distinguish evaluation/admissibility state, returned value when defined, and the restoration signature required before lawful reuse. Exact relation ablation is prospectively defined and protocol-relative. Where no lawful exact ablation exists, or lawful protocols disagree without a prospectively selected resolution rule, the load-bearing classification remains unknown rather than being forced to zero or one.

A relation is load-bearing for the declared future family when lawful exact ablation changes at least one declared evaluation. A closure is future-sufficient only when each declared operation is directly preserved or protected by a guaranteed reopening route that restores sufficient lower structure before an omitted distinction becomes consequential.

The paper therefore treats recursive reuse as an explicit scientific object:

```text
local closure
→ reuse as a constituent in a wider composition
→ widened future-operation family
→ previously omitted relation becomes decision-bearing
→ preserve, refine, reopen, reject, or withhold as the owning domain requires
```

Genuine absence remains absent. The schema does not require every domain to instantiate uncertainty, authority, observer state, geometric position, or any other optional coordinate merely for visual or terminological symmetry.

## Bell/CHSH adversarial calibration

Bell/CHSH is used as a hostile known-answer calibration, not as a source of post-hoc quantum novelty.

For a full binary behaviour

```math
P=\{p(a,b\mid x,y)\},
```

with correlators

```math
E_{xy}
=\sum_{a,b}ab\,p(a,b\mid x,y)
```

and CHSH score

```math
S=E_{00}+E_{01}+E_{10}-E_{11},
```

v0.3 records three useful interface results:

1. different correlator tuples can share the same scalar `S`, so a score-only closure can be valid for score questions while failing a widened correlator question;
2. full behaviours can share the same four correlators while differing in signalling marginals, so a correlator-only closure cannot certify general no-signalling and must reopen the probability/marginal object when the target widens;
3. holding `E_{00}=E_{01}=E_{10}=1/\sqrt2`, changing only `E_{11}` from `-1/\sqrt2` to `0` changes `S` from `2\sqrt2` to `3/\sqrt2`; at the stated unbiased-marginal correlator scope both tuples satisfy the appropriate native quantum-correlator criterion, so this is an object-level targeted ablation/restoration example inside the native quantum-correlator set.

The physical Phase-0 verdict is **NULL**:

- no new Bell inequality;
- no independent Tsirelson derivation;
- no new physical mechanism.

Established Bell/Fine, operational no-signalling, Tsirelson, Landau, Masanes and related native results retain ownership of the corresponding boundaries.

## Tetrahedral result

The unrestricted correlator object

```math
(E_{00},E_{01},E_{10},E_{11})
```

has four independent real coordinates before added constraints. An ordinary tetrahedral barycentric point has three independent coordinates because its four barycentric weights sum to one. A privileged lossless ordinary tetrahedral carrier for unrestricted CHSH correlators is therefore not earned.

This does not prohibit tetrahedral representation. Labelled-vertex, restricted-submanifold, or target-specific lossy charts remain open where their roles are independently justified and any omitted information has a lawful reopening route. A stronger geometric or physical claim requires a separately measured advantage or discriminator.
