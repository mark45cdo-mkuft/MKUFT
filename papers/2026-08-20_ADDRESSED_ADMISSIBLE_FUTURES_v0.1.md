## Abstract

Many dynamical systems are described by their present state, yet the variables required to predict lawful continuation may include momentum, phase, retained history, boundary conditions, relational context, or other coordinates not visible in an instantaneous snapshot. This paper formalises that distinction by introducing the **Addressed Admissible Future (AAF)**: the future-equivalence object generated by a state description sufficient for a declared target, horizon, intervention class and tolerance. An Address is therefore not defined as a preferred list of variables. It is defined by predictive closure: histories share an effective Address only when they induce the same target-relevant admissible future, exactly or within a declared tolerance.

The second move concerns recovery. Present viability and future recoverability are treated as distinct dynamical objects. Inside the admissible future, the restorative subset contains trajectories that preserve declared viability constraints, reach a restored target, solve the required task and remain inside an irreversible-loss boundary. A **restorative-future reserve** measures how much admissibility structure must be deformed before every sufficient restorative continuation is lost. This makes “load-bearing relation” counterfactual: a relation is load-bearing relative to a declared functional future when removing it materially deforms that future, even if the relation carries little present flow.

AAF is not a separate law stack beside MKUFT. It is a future-object specialisation of the existing recursive S-I-P-O addressed-update architecture: addressed state → admissibility → lawful continuation → realised transition/registration → readdressing. The framework is anchored to established mathematics in predictive-state theory, computational mechanics, viability theory, control-barrier methods and graph cuts. Biological results concerning p21/Cdk2 state velocity and p53 phase resetting are used as calibration examples, not claimed as AAF discoveries. The paper closes with a preregistered first test using public single-cell p21 data. No empirical result is claimed here.

**Keywords:** addressed state; predictive sufficiency; admissible future; viability; recoverability; load-bearing relation; minimum-sufficient address frontier; restorative trajectory; state history; p53; p21; dynamical systems.

## 2. Future-sufficient Address

Let `H_t` denote retained history and let `Σ` denote the declared target, horizon, physical/transition model, environment/boundary class, admissible intervention class, measurement resolution and other genuinely load-bearing typed constraints.

Two histories are future-equivalent when

```math
H_t \sim_{\Sigma} H'_t
\iff
\mathbb P_{\Sigma}\!\left(X^+\mid H_t,\pi\right)
=
\mathbb P_{\Sigma}\!\left(X^+\mid H'_t,\pi\right)
\quad
\forall\pi\in\Pi_{\mathrm{adm}}.
```

The effective Address is

```math
\boxed{A_t=[H_t]_{\sim_{\Sigma}}.}
```

For a target `q`, candidate coordinate description `Θ`, declared discrepancy `d` and tolerance `ε_q`, define

```math
\boxed{
\mathcal R_q(\Theta)
=
\sup_{\Theta(h)=\Theta(h')}
 d\!\left(
 \mathcal L(q^+\mid h),
 \mathcal L(q^+\mid h')
 \right).
}
```

`Θ` is target-sufficient when

```math
\mathcal R_q(\Theta)\leq\varepsilon_q.
```

The operational rule is:

> **A coordinate belongs in Address only when omitting it merges histories whose declared future laws materially differ.**

Velocity, phase, schedule, hysteresis, connectivity or another variable can therefore enter Address when it performs predictive/interventional work and drop out when it does not.

## 3. Minimum-sufficient address frontier

Under lawful augmentation,

```math
\Theta_1\subseteq\Theta_2
\quad\Longrightarrow\quad
\mathcal R_q(\Theta_2)\leq\mathcal R_q(\Theta_1).
```

Define

```math
\mathcal S_q
=
\{\Theta:\mathcal R_q(\Theta)\leq\varepsilon_q\},
```

and

```math
\mathcal M_q
=
\{\Theta\in\mathcal S_q:
\text{no proper lawful subset is sufficient}\}.
```

`\mathcal M_q` is the **minimum-sufficient address frontier**. It can contain several incomparable minimal descriptions and can move as the system changes. This replaces “what is the one correct scale?” with the narrower test: which minimum typed descriptions close the declared future target now?

## 4. Present viability and restorative future

Let

```math
\mathcal V(a)=\{z:h_j(z;a)\geq0\ \forall j\in J(a)\},
```

with present viability margin

```math
\boxed{H(z,a)=\min_{j\in J(a)}h_j(z;a).}
```

Present viability does not imply recoverability.

Let `G(A_t)` be a restored target, `Q(γ)` task sufficiency with threshold `κ`, and `D_irr(γ)` a vector of declared irreversible losses bounded by `d_R`. The restorative future is

```math
\boxed{
\Gamma_R(A_t)
=
\left\{
\gamma:
\gamma\subseteq\mathcal V(A_t),
\ \gamma\rightarrow G(A_t),
\ Q(\gamma)\geq\kappa,
\ D_{\mathrm{irr}}(\gamma)\preceq d_R
\right\}.
}
```

Its existence indicator is

```math
\boxed{
\chi_R(A_t)=\mathbf 1[\Gamma_R(A_t)\neq\varnothing].
}
```

## 5. Restorative-future reserve

Let `\mathcal D` be a preregistered family of meaningful admissibility-structure deformations with cost `c(Δ)`. Define

```math
\boxed{
\rho_R(A_t)
=
\inf_{\Delta\in\mathcal D}
\left\{
c(\Delta):
\Gamma_R(A_t;\Delta)=\varnothing
\right\}.
}
```

A system can therefore remain presently viable while its restorative route structure becomes fragile:

```math
H>0
\qquad\text{while}\qquad
\rho_R\downarrow0.
```

## 6. Load-bearing relation by deformation

Let `C` be a relation or coalition and let `Ψ` be a preregistered future readout. Define

```math
\boxed{
\Lambda_C^{\Psi}(A_t)
=
\Psi(\Gamma_R(A_t))
-
\Psi(\Gamma_R^{-C}(A_t)).
}
```

A relation is load-bearing relative to `(A_t,Ψ)` when its controlled removal materially deforms the declared future readout. It is terminally load-bearing when removal destroys every sufficient restorative continuation.

This is intentionally different from centrality, current flow, repetition or visual prominence. A dormant backup can be strongly load-bearing; a heavily used edge can be replaceable.

## 7. Graph approximation

For a finite directed/time-expanded network with edge capacity `c_e`, the graph estimator of restorative reserve from present node `s` to restored target set `G` is

```math
\boxed{
\widehat{\rho}_R(s,G)
=
\min_{C\in\mathrm{Cut}(s,G)}
\sum_{e\in C}c_e.
}
```

Raw path count is not equivalent to bottleneck reserve. A large number of paths may all depend on one fragile cut.

## 8. Recursive readdressing

The central recursion is

```math
\boxed{
A_t
\rightarrow
\mathcal F_t^+
\rightarrow
\tau_t
\rightarrow
A_{t+1}
\rightarrow
\mathcal F_{t+1}^+.
}
```

Traversal changes retained history; retained history can change Address; Address changes admissibility; admissibility changes the next future.

## 9. Calibration examples

A bounded-braking example shows why position alone can be future-incomplete. For

```math
\dot x=v,
\qquad
\dot v=u,
\qquad
|u|\leq u_{\max},
```

the stopping distance for positive velocity is

```math
\boxed{d_{\mathrm{stop}}=\frac{v^2}{2u_{\max}}.}
```

Two bodies at the same position can therefore have different restorative futures if their velocities differ.

Biologically, Venkatachalapathy et al. reported that p21/Cdk2 position plus state velocity predicts quiescence/proliferation fate better than position alone, and later showed that repeated DNA-damage stimulus timing can reset p53 phase and alter downstream p21/arrest dynamics. AAF uses these as calibration examples of the Address rule. It does not claim the biological findings as new.

## 10. Preregistered first test

The first empirical route uses public p21 single-cell data associated with the 2025 p53 phase-resetting study.

The fixed prospective question is whether future-structure readouts predict individual arrest escape beyond conventional summaries using the same pre-outcome information.

The paper freezes:

- prediction time `t*=5.0 h`;
- no post-5 h predictor data;
- escape versus maintained arrest through 8 h as inherited from the source analysis;
- pre-5 h p21 history, regimen and elapsed dose timing as the candidate Address;
- leave-one-biological-replicate-out evaluation;
- `\chi_R` and `\rho_R` as AAF readouts;
- a regularised same-history model as the crucial comparator;
- history scrambling, relation rewiring and label-permutation controls;
- a strong result only when the AAF readouts improve held-out performance and the real directed relation structure beats the rewired control.

If a conventional same-information model performs equivalently, topology/reserve does not earn independent predictive credit in that test.

## 11. Failure boundary

AAF contracts if:

- proposed Address coordinates do not reduce held-out future residual;
- a simpler ordinary state closes the target equally well;
- reserve adds no information beyond adequate state/history baselines;
- the claimed early reserve warning appears only at or after conventional failure;
- claimed coordinates fail ablation/restoration;
- rewired relation structure performs as well as the real structure;
- cross-domain application requires changing the definitions after observing outcomes;
- predictive associations are promoted into causal claims without intervention or a justified causal model.

## 12. Relation to established mathematics

AAF recruits established ingredients rather than claiming them independently: computational mechanics and predictive-state representations for future sufficiency; viability/capture theory and control-barrier methods for constrained continuation; max-flow/min-cut for a finite bottleneck estimator; and optional Hodge methods only when recurrent flow itself proves incrementally predictive.

The candidate contribution is the composition:

```text
future-sufficient typed Address
→ admissible future
→ restorative subfuture
→ restorative reserve
→ counterfactual load-bearing relation
→ realised transition
→ recursive readdressing.
```

## 13. Claim boundary

AAF does **not** establish a new force or field, a universal biological repair law, a universal moral metric, a universal graph carrier, a finite sufficient state for every system, a causal effect from predictive load, observer-caused physics, independent I→P coupling, or fundamental quantum-gravity dynamics.

Its present burden is narrower and falsifiable:

> **For a declared target, horizon, intervention/environment class and tolerance, identify the minimum retained Address that closes the target-relevant future; then measure whether a sufficient restorative subfuture exists, how robust it is to admissibility deformation, and which typed relations are counterfactually load-bearing for that future.**
