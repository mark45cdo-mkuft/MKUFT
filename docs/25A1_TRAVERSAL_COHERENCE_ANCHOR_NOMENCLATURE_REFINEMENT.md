## Purpose

Module 25A already distinguishes node-localised anchor effects, redundant anchor networks, latent/stress anchors, junction-only nodes, false anchors, and traversal-neutral cases. The underlying functional class is therefore broader than one node.

This note gives that broader class a stable name while preserving the existing node-specific term.

## Traversal Coherence Anchor

A **Traversal Coherence Anchor (TCA)** is a signature-bearing structure whose tested presence supports reproducible convergence, compatibility, correction, reconstruction, or recovery during traversal beyond what is explained by generic connectivity, relation count, graph centrality, content volume, resource access, or the strongest simpler native account.

A TCA may be:

- concentrated in one node;
- distributed across a redundant anchor network;
- carried by a typed relation set or interface where the domain supports that object;
- latent under ordinary conditions and load-bearing only under a declared stress/repair regime.

The term does not make all of those forms equivalent. Their native measurements, controls, mechanisms, and falsifiers remain domain-specific.

## Fundamental Traversal Coherence Node retained as subtype

**Fundamental Traversal Coherence Node (FTCN)** remains the node-localised subtype.

A candidate node earns FTCN status only when the node-specific effect survives the existing Module 25A burden: relation-preserving reroute, fair substitution, perturbation/recovery, and held-out or transfer testing as appropriate.

```text
Traversal Coherence Anchor
→ umbrella functional class

Fundamental Traversal Coherence Node
→ node-localised subtype

Redundant anchor network
→ distributed candidate subtype where coalition deformation carries the effect
```

Historical uses of FTCN remain valid provenance. This is a prospective live-canon clarification, not a retrospective claim that earlier terminology was scientifically false.

## Reduction and red-team rule

The broader name must not become an escape from the stronger node assay.

- If a fair reroute preserves the complete function, the original node is not an FTCN merely because the wider system remains anchored.
- If coalition testing shows the effect is distributed, classify the surviving distributed object rather than forcing node-localisation.
- If an established native construct explains the full effect with equal or better discrimination, retain that native ownership.
- If removal or substitution changes no declared prediction, recovery, route, reconstruction, or held-out function, do not promote the candidate as a TCA.
- High centrality, salience, symbolic importance, or repeated mention alone are insufficient.

> **The umbrella widens the address of the candidate; it does not lower the evidence threshold.**
