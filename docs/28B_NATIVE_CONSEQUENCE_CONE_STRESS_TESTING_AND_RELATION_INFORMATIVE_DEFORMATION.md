## 1. Purpose

Module 28 already requires deformation or ablation of a proposed load-bearing relation while preserving ordinary resources. Module 33S7 already requires the state, challenge, boundary/environment, measurement and stochastic model to be addressed separately before a future split can be assigned to hidden state.

This module sharpens one experimental-design question left between those rules:

> **In what environment should a load-bearing relation be stressed if the aim is not merely to break it, but to learn what its failure means inside the native system?**

A deformation performed in an environment that is too thin may show only that the relation can be broken in isolation. The native dependencies, compensating routes, downstream observables, recovery paths or parent-scale consequences needed to localise the failure may be absent.

The opposite error is also possible. An unnecessarily rich or poorly controlled environment can contain enough compensation, collateral coupling and uncontrolled variation that the relation-specific effect becomes impossible to attribute.

The methodological target is therefore the **smallest target-sufficient native consequence cone**: enough native structure for the proposed relation to express its real target-relevant consequences, but no more uncontrolled structure than the attribution problem requires.

## 2. Definition

Let `r` be a candidate load-bearing relation at Address `a`. Fix before confirmatory testing:

- target `q`;
- prediction horizon `Δ`;
- admissible intervention/deformation family `U`;
- environment and boundary class `E`;
- measurement/registration family `O`;
- discrepancy and closure tolerance;
- strongest adequate ordinary null family.

Define

```math
\mathcal K_q(r\mid a,E,\mathcal U,\Delta)
```

as the smallest practically adequate native neighbourhood containing the relations, interfaces, observables and recovery/parent links whose presence is required for a deformation of `r` to express its declared target-relevant downstream consequences.

`\mathcal K_q` is an experimental-design/addressing object. The word **cone** does not imply a relativistic light cone, a new causal metric, a physical field, or a universal graph geometry.

Depending on the native domain and target, the cone may include:

- direct dependencies and dependants of `r`;
- boundary/environment relations capable of carrying the same result;
- compensating or redundant routes;
- target-relevant observables and readouts;
- recovery/restoration paths;
- parent or scale-return relations;
- bounded history needed to distinguish futures;
- ordinary baseline mechanisms that could mimic the deformation.

The content of the cone is earned by the native system and declared target. It is not a fixed MKUFT inventory.

## 3. Why an isolated break can be weak evidence

Suppose removing `r` produces a large performance loss in a stripped-down test fixture.

That result may establish that `r` was necessary **for that fixture**. It does not by itself establish:

- that `r` is load-bearing in the native system;
- that the same downstream relation fails first natively;
- that no redundant route compensates;
- that the parent-scale object loses closure;
- that the observed loss is not generic intervention damage;
- that restoration of `r` restores the predicted native signature;
- or that `r`, rather than an adjacent resource removed with it, owns the effect.

A dramatic break is therefore not automatically a discriminating break.

> **Do not merely break the relation. Break it where the system can tell you what the break means.**

## 4. Too thin, target-sufficient, too rich

The design problem has two boundaries.

```text
too thin
→ native consequence carriers are absent
→ break may be real but ownership/localisation is weak

target-sufficient native cone
→ relation can express its predicted downstream signature
→ ordinary compensation and recovery remain visible where relevant
→ attribution remains tractable

too rich / uncontrolled
→ many relations move together
→ compensation or collateral coupling can hide the owner
→ localisation weakens
```

This is not a demand to simulate or reproduce an entire natural ecology for every experiment. The burden is **target sufficiency**, not maximal realism.

A reduced model is acceptable when the removed context cannot change the declared target, attribution, compensation, recovery or parent-scale interpretation beyond tolerance. A larger native environment is required only when the omitted context can do that work.

## 5. Relation-informative deformation

A stress is relation-informative when its possible outcomes can discriminate at least one declared question such as:

- whether `r` is load-bearing for `q`;
- which neighbouring relation deforms first;
- whether redundancy compensates;
- whether local failure reaches the governing parent;
- whether history becomes newly decision-bearing;
- whether a scale transition is required;
- whether a representation change restores closure;
- whether a proposed recovery route actually restores the future-bearing relation.

The strongest evidence unit is therefore often an ordered **deformation signature**, not an undifferentiated performance drop.

For example, a preregistered signature might be:

```text
r intact
→ observables A,B,C remain inside baseline relation

deform r
→ A changes first
→ B changes only if compensator c saturates
→ parent outcome C changes only beyond threshold τ

restore r / minimal typed repair
→ ordered deformation contracts toward baseline
```

The exact variables and ordering must come from the native domain, not from this schematic.

## 6. Minimal matched stress family

Where lawful and feasible, select only the controls capable of changing attribution. A useful family can include:

### Native baseline

`r` intact inside the declared native consequence cone.

### Targeted deformation

Remove, scramble, weaken or otherwise deform `r` while preserving ordinary resources as far as the native experiment permits.

### Thin/toy control

Apply the nominal deformation in a reduced environment lacking one or more native consequence carriers. This can show which conclusions depend on the richer native relation surface.

### Restore

Restore `r` or the smallest typed repair and test whether the predicted deformation contracts.

### Compensation control

Where redundancy is plausible, preserve or vary the strongest ordinary compensating route rather than misclassifying successful compensation as absence of load.

### Boundary/environment control

Vary the medium or boundary only where it can plausibly carry the same observed signature.

### Generic-damage control

Where the intervention itself can degrade the system, compare against a matched disturbance that removes comparable resource without selectively targeting `r`.

Not every experiment needs every arm. Adding controls that cannot change the interpretation is not methodological strength.

## 7. Native-ownership and causal restraint

A predicted deformation after targeting `r` does not automatically establish that `r` is the mechanism owner.

Before relation-specific promotion, test adequate alternatives including:

- collateral resource loss;
- challenge mismatch;
- boundary/environment mismatch;
- measurement or registration disturbance;
- generic intervention damage;
- ordinary redundancy or compensation;
- timing, selection or stochastic effects;
- a lower- or higher-scale mechanism already sufficient to carry the result.

Where the certifying model contains the same relation under test, use an independent continuation source where possible, following 33S7's independent-continuation burden.

The smallest surviving adequate owner receives the credit.

## 8. Connection to Module 28 promotion gates

This module refines, rather than replaces, Module 28 Gate 8.

A Tier-2 or Tier-3 relation-deformation claim is stronger when it prospectively specifies:

1. the target-sufficient native consequence cone;
2. the relation-specific deformation;
3. the expected ordered native signature;
4. the strongest ordinary compensation/damage/boundary nulls;
5. the restoration signature;
6. the conditions under which no target-relevant deformation should occur.

A toy ablation may remain useful at Tier 0 or Tier 1, or as a component of a higher-tier test. Its evidential scope should match the environment in which the result was earned.

## 9. Connection to FSSR and future sufficiency

FSSR asks whether states currently treated as equivalent split under an admissible separating future. Native consequence-cone design asks whether that separating future contains enough native relational structure for the split to be meaningfully localised.

The two operations therefore compose as:

```text
candidate state equivalence
→ choose a lawful separating challenge
→ preserve the smallest native consequence surface required by the target
→ propagate and register the result
→ localise split / compensation / null
→ recruit the smallest missing typed distinction if required
→ restore / retest
→ preserve or readdress
```

If removing native context changes which futures are reachable or which relation owns the split, that context was not safely disposable for that target.

If the reduced experiment and native-cone experiment are prospectively equivalent within tolerance, the smaller design is preferred.

## 10. Scale return

A local deformation does not become globally important merely because it is large. Conversely, a local intervention can matter at a parent scale when it changes a governing parent future.

When a local stress changes a parent-scale closure, recovery, prediction or admissible route, readdress the changed bundle at the parent scale and test the consequence there. The larger scale does not automatically win; the scale that owns the declared consequence must carry the claim.

## 11. Failure and contraction conditions

The native consequence-cone refinement contracts or adds no value when:

- ordinary ablation with standard controls already supplies the same discrimination;
- the proposed cone cannot be operationally distinguished from arbitrary context expansion;
- native versus reduced environments produce no target-relevant difference;
- the claimed relation-specific signature is reproduced by generic damage or an adequate simpler mechanism;
- restoration does not recover the predicted relation;
- cone selection is fitted retrospectively to the observed result;
- increasing ecological realism only adds uncontrolled variance without improving localisation;
- the language does not change experiment design, prediction, attribution or closure.

A null is informative. If the relation survives the strongest target-sufficient native attack, preserve it provisionally for the declared target, regime, horizon and tolerance. Do not invent a harsher but less relevant torture merely to force failure.

## 12. Claim boundary

This module is a methodological proposal about experimental context, ablation and relation localisation.

It does **not** establish:

- a new physical interaction;
- a universal causal cone;
- a new graph-theoretic theorem;
- that naturalistic experiments are always superior to reduced experiments;
- that every relation requires ecological testing;
- that deformation proves mechanism;
- or that MKUFT terminology supersedes established native experimental-design methods.

Where a native field already has a sufficient concept or design for the same operation, that native ownership remains primary. MKUFT earns value only if this formulation improves the explicit preserve/reopen, localisation, control or scale-return discipline.

## 13. Canonical compression

```text
load-bearing relation r
→ attack at the smallest native environment that preserves the consequences needed to judge r
→ predict the native deformation signature before confirmatory testing
→ preserve compensation, boundary and generic-damage nulls where they can change attribution
→ restore / retest
→ return the smallest surviving owner
→ readdress upward only when the parent future actually changes
```

> **Too little ecology can give an uninformative break. Too much can hide the owner. The useful stress is the smallest native consequence surface on which failure can generate discriminating relational information.**
