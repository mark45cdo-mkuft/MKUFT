## 1. Purpose and placement

ATLD v1.0 asks whether meaningful typed dependency architecture plus active traversal causes reproducible functional gain beyond matched controls and whether particular relations are load-bearing under controlled deformation.

ATLD 2 keeps that causal grammar fixed and asks a different question:

> **Can a long-horizon system remain strong on the original ATLD readouts while still failing in a materially important way that the seven-coordinate measurement body does not isolate cleanly?**

The published successor proposes five candidate residual coordinates and a method for deciding whether those coordinates deserve to remain. This module owns the live MKUFT measurement fold of that result. It does **not** declare a twelve-dimensional ontology and does not replace Modules 24A, 24B, or 25.

The live chain is:

```text
24A active traversal / matched architecture gain
→ 24B strongest fair null and relationship specificity
→ 25 controlled deformation / load-bearing relation test
→ 25B residual measurement audit / candidate retention or collapse
→ 25C residual instrument generation / protected discovery boundary
```

## 2. Frozen predecessor body

The predecessor vector remains:

```text
Y1 = [A, M, C, K, G, L, E]
```

where the public ATLD paper defines the readouts as:

- `A` — task accuracy;
- `M` — multi-entry convergence/reconstruction;
- `C` — contradiction detection/localisation;
- `K` — correction propagation;
- `G` — calibration;
- `L` — branch-failure localisation/repair;
- `E` — efficiency plus evidence-path validity.

ATLD 2 does not reinterpret those seven after seeing the successor candidates. Their causal role remains the frozen predecessor surface.

## 3. Candidate successor body

The candidate measurement body is:

```text
Y2 = [A, M, C, K, G, L, E, O, U, R, V, F]
```

The added candidates are:

### O — exact object/address custody

Does the system remain attached to the exact governing object and lawful lineage?

The direct failure is silent object drift. The mirror failure is stale-object lock: refusing a legitimate readdress when evidence or authority lawfully changes the parent.

### U — permission/action-state integrity

Does the system distinguish what can be reasoned about from what may actually be executed?

The direct failure is unauthorised action. The mirror failure is false prohibition. A system does not earn safety by refusing every lawful action.

### R — future-sufficient continuity/re-entry fidelity

After interruption or state compression, does the recovered state preserve the same materially lawful continuation set?

Textual identity is not required. Future-equivalence is. Missing a branch that changes the next lawful action lowers R; carrying stale/superseded branches also lowers R.

### V — receiver-side closure

Does the declared carrier deliver an object the intended receiver can reconstruct correctly?

Source correctness is not enough. A correct source object with a broken carrier, stale destination, or receiver-driven substitution is an incomplete delivery state.

### F — parent fixed-point closure

Does the system stop when no reachable lawful in-budget action can still change the declared parent, or when the remaining actions are attached to genuine blockers?

The direct failure is premature closure. The mirror failure is post-fixed-point audit theatre.

## 4. Measurement heterogeneity is intentional

The twelve coordinates are not assumed to be one flat mathematical species.

- the original seven are primarily performance/evidential readouts;
- O/U/R/V are integrity-state readouts;
- F is a terminal reachability/stopping readout with two-sided error structure.

Therefore a visually convenient twelve-axis plot must not be mistaken for a claim that the coordinates form an orthogonal Euclidean state space.

## 5. Residual discovery rule

A new failure class is not automatically a new coordinate.

A candidate residual `x` earns a dedicated coordinate only if the failure cannot be recovered with non-inferior diagnostic risk and lower/equal complexity from the retained measurement body under matched information and budget.

Operationally:

```text
new residual observed
→ map it against existing coordinates and derived route support
→ identify primary fault versus downstream shadows
→ remove candidate x
→ ask whether retained body recovers the hidden failure fairly
→ forbid x from being smuggled back through a renamed oracle/rubric
→ test selective direct + mirror deformation
→ test held-out worlds / neutral domains / other systems
→ retain, merge, demote, or kill x
```

This rule is the live answer to **measurement-body self-expansion**. Novelty is not earned because a new label can be written.

Module 25C states the higher-order methodological consequence of this rule and the associated disclosure boundary without adding a new coordinate or altering the frozen ATLD 2 publication.

## 6. No-smuggling rule

Coordinate removal is meaningless if the evaluator reconstructs the missing distinction from an x-specific oracle or renamed score field.

When `x` is removed, the recovery arm may use only:

- the remaining preregistered measurement body;
- metadata available in every condition;
- generic run features declared independently of `x`.

A new field or rubric whose sole purpose is to restore `x` is reintroduction, not recovery.

## 7. Causal-shadow control

One upstream fault can deform many downstream outputs.

ATLD 2 therefore separates:

```text
PRIMARY DEFORMATION
PROPAGATED DEFORMATION / CAUSAL SHADOW
INDEPENDENT CO-FAILURE
UNRESOLVED COUPLING
```

A targeted repair of `x` should restore only the x-specific relation where the synthetic world permits it. If a downstream coordinate recovers with that repair, its prior movement is evidence for a causal shadow rather than a second independent failure. If it stays deformed, co-failure or unresolved coupling remains live.

Do not multiply scientific claims by counting one wound at several downstream surfaces.

## 8. Route support is derived, not a thirteenth coordinate

For an observable traversal route:

```text
SUPPORTED
FAILED
UNRESOLVED
```

are transition-level route states, with the first demonstrated break localised when a failure exists.

Endpoint correctness does not erase a broken route. Equally, a route-support witness does not need a new undifferentiated coordinate when the failure itself is already owned by A/M/C/K/G/L/E/O/U/R/V/F.

The 23 August 2026 Release Relay pilot supplied a practical example. The foreign comparator's RR-14 error was already captured by `L` plus route support/first-break localisation, with calibration movement in `G`. No thirteenth coordinate was earned.

## 9. Anti-Goodhart mirror rule

Every retained coordinate must survive its mirror failure.

Examples:

```text
object drift ↔ stale-object lock
unauthorised action ↔ false prohibition
continuity loss ↔ stale-state capture
receiver failure ↔ receiver-pleasing substitution
premature closure ↔ audit theatre
```

The same principle applies to the predecessor readouts: overconfidence cannot be repaired by strategic underconfidence; missed contradiction cannot be repaired by contradiction flooding; under-propagation cannot be repaired by over-propagation.

A metric that can be maximised by collapsing onto one pathological extreme has not closed its evaluation burden.

## 10. Exploratory pilot placement

The published ATLD 2 paper reports a fixed 15-case Release Relay execution pilot.

The public experimental record is deliberately bounded:

- Google Gemini was first run in Fast mode and then with Pro mode explicitly selected;
- Deep Think was not enabled;
- the Pro trace is the scored foreign comparator;
- a private structured condition was run on the same packet;
- that private condition was non-blind/design-adjacent and is therefore a worked application, not independent evidence of superiority;
- the pilot is descriptive and does not validate O/U/R/V/F.

The pilot's value is that the measurement surface returned a **shaped diagnostic profile** rather than only an endpoint score.

## 11. Promotion and collapse rule

Candidate coordinate `x` remains provisional until it survives:

1. reproducible direct selective deformation;
2. reproducible mirror deformation;
3. coordinate-removal diagnostic-loss testing;
4. strongest-existing-coordinate substitution;
5. coalition testing where multiple retained coordinates may jointly recover the failure;
6. causal-shadow accounting;
7. no-smuggling audit;
8. held-out neutral-domain testing;
9. cross-model/system replication;
10. evaluator and scoring reproducibility appropriate to the task.

If `x` fails, merge, demote, or remove it.

If all five candidates collapse, ATLD 2 remains useful as a sharper validation/security extension of ATLD v1.0, but the twelve-coordinate successor claim does not survive.

If a reproducible material failure survives the complete retained body under matched conditions, only then should another candidate coordinate be proposed.

## 12. Relationship to MKUFT public canon

ATLD 2 is an AI-evaluation/methodological branch of MKUFT rather than a physical law claim.

Its strongest public contribution back into MKUFT is procedural:

- exact object identity must stay separate from local correctness;
- action authority must stay separate from capability;
- saved text must stay separate from future-sufficient re-entry;
- source correctness must stay separate from receiver reconstruction;
- stopping must be tied to the addressed parent rather than to a fixed amount of checking;
- a new residual must first be tested against existing owners before new anatomy is added;
- internal self-audit can generate candidates but cannot certify its own empirical truth.

These relations are reusable across the research stack without asserting that an AI-evaluation coordinate is itself a physical coordinate of nature.

## 13. Recursive learning imported into the public SOP

The ATLD 2 development and publication sequence exposed two reusable process lessons.

### 13.1 Residual novelty gate

A newly visible failure is cheap to name and expensive to promote. Before adding a new coordinate, controller, module, or law-like object, test whether the existing body already owns it through direct readouts, derived route support, causal shadows, or coalition recovery.

### 13.2 Frozen-carrier identity gate

Correct metadata does not prove that the correct final file is attached. During the ATLD 2 publication sequence, an earlier shorter carrier and the final benchmark-integrated carrier could share the same broad title/metadata. The decisive identity was page count plus checksum plus reader-side inspection of the benchmark sections.

Therefore:

```text
right title + right DOI + right metadata
≠
right frozen carrier
```

Closure requires verifying the exact bytes or checksum-bearing object actually published.

These lessons are also routed into the standing research/publication SOPs.
