## 1. Purpose

The Future-Sufficient Address programme usually treats a failed direct representation in two ways:

```text
DOWN
→ restore the minimum omitted distinction that changes the declared future

UP
→ move to an earned effective/higher address that is sufficient for the declared property/use
```

There is a third lawful possibility:

```text
SIDEWAYS
→ change the interrogation or representation so that the unresolved distinction
  becomes irrelevant, cancelable, quotientable, or predictably invertible
  while the declared target is preserved.
```

The key point is modest but useful:

> **An unknown coordinate is not automatically a coordinate that must be learned. Before enlarging the state, test whether a lawful target-preserving query makes that coordinate unnecessary for the declared operation.**

This is a methodological addition to the FSAI/LBLP repair family, not a claim that every hidden variable can be removed by clever questioning.

## 2. Basic construction

Let `x` be a target-bearing state and let an unknown nuisance transform `g` belong to a declared family `G`. A direct readout may depend on `g` in a way that prevents target closure.

Seek a transformed query/readout `Q` with one of two properties.

### Invariant form

```math
\boxed{
Q(g\cdot x)=Q(x)
\qquad \forall g\in G.
}
```

The nuisance action disappears from the declared readout.

### Equivariant / predictably invertible form

```math
\boxed{
Q(g\cdot x)=h_g\!\left(Q(x)\right)
}
```

where the induced action `h_g` is known well enough that the target can be recovered by a predeclared inversion, quotient, or equivalence operation.

The second case matters because useful sideways readdressing need not make the nuisance literally invisible. It is enough for the nuisance action to become **known in the transformed interrogation geometry**.

## 3. Toy calibration: the truth/lie guard

The familiar two-guard puzzle gives a compact finite example.

One guard applies an identity-like truthful map and the other applies a negating map. A direct answer is therefore contaminated by an unknown operator. The standard second-order question asks one guard what the other guard would indicate. The two possible operator compositions collapse to the same complemented door, after which one known inversion returns the target.

The scientific lesson is not the wording of the riddle and not a claim of novelty for the puzzle. It is the structural move:

```text
direct target + unknown nuisance operator
→ compose/readdress the query
→ nuisance action becomes common/predictable
→ one declared inverse recovers target
```

The hidden identity of the queried guard has not been discovered. It has become **unnecessary for that decision**.

## 4. Three-way address repair

When a declared state/query fails future sufficiency, the repair search can therefore be written:

```text
DIRECT FAILURE
→ identify exact target + omitted/nuisance distinction
→ test strongest ordinary explanation / measurement error / model error first
→ then compare:

   DOWN
   restore minimum decision-bearing lower detail

   UP
   instantiate the coarsest earned higher/effective object that closes the target

   SIDEWAYS
   transform interrogation/representation so the nuisance distinction
   no longer needs to be retained for the declared target
```

The winner is not chosen by elegance. It is chosen by target closure, cost, robustness, and the existing strongest-fair-null discipline.

This adds no new controller. `DOWN` remains ordinary FSAI restorative readdressing; `UP` remains property/use-relative effective-object or law-descent promotion; `SIDEWAYS` is a representation/interrogation readdressing inside the same target-relative sufficiency burden.

## 5. Prospective burden

A sideways result is valid only when the following are fixed before outcome inspection to the extent the domain permits:

1. the target quantity/property/decision;
2. the nuisance-transform family `G` or an independently justified approximation to it;
3. the candidate query/readout `Q`;
4. the invariance/equivariance criterion;
5. the inversion/quotient/recovery rule where required;
6. the failure tolerance and comparator.

Post-hoc discovery may still generate a candidate, but it does not count as prospective confirmation of the transformation.

## 6. Failure modes

### Target-loss false invariance

A query may appear invariant only because it discards the target distinction as well.

```text
nuisance erased
+ target erased
→ FAIL
```

### Incomplete nuisance family

A transform may cancel one nuisance branch while a hidden asymmetry remains elsewhere. If the declared `G` was incomplete, closure is not earned.

### Reparameterisation-only novelty

An invertible or quotient representation can be useful without adding evidence or physics. Sideways closure therefore does not by itself raise confidence, establish a mechanism, or create a new law.

### Post-hoc operator choice

Choosing `Q` after observing which transformation makes the answer look clean is calibration leakage, not prospective discrimination.

### Forced quotient

If the omitted distinction changes the declared future, it is load-bearing and may not be quotiented away merely for simplicity. The correct move is `DOWN`, `UP`, or unresolved status according to the owning domain.

## 7. Relation to FSAI

FSAI asks whether states called equivalent remain equivalent across the declared admissible future.

Sideways interrogation adds a complementary question:

> **Is the apparent state insufficiency intrinsic to the target, or only to the chosen interrogation?**

Let a direct representation `R` fail because histories/states differing by nuisance transform `g` produce different direct readouts. If a lawful `Q` preserves the declared target while satisfying the required invariance/equivariance relation, the nuisance coordinate is not load-bearing **for that transformed future-use family**.

This does not erase the coordinate from reality or from other tasks. A later target may require reopening it.

Thus:

```text
coordinate not needed for Q-target
≠ coordinate nonexistent
≠ coordinate irrelevant for all futures
```

## 8. Relation to Layer Before Law

LBLP already says:

```text
closure failure
→ test state/address adequacy
→ only then treat residual as evidence for law/model revision
```

The present refinement expands the middle step:

```text
closure failure
→ test whether direct interrogation is itself poorly conditioned
→ try lawful target-preserving sideways readdressing
→ if SIDEWAYS closes, do not manufacture extra state or new law
→ if SIDEWAYS fails, continue with minimum restoration / higher-address / model-law tests
```

This is especially useful where the scientific nuisance is known to act by a symmetry, relabelling, calibration offset, sign convention, observer/readout convention, or another transformation with a controlled mathematical action.

## 9. Cross-domain transfer boundary

The structural pattern may recur in statistics, control, physics, computation, experimental design, semantics, provenance, or human systems, but the carrier must be rebuilt locally.

Examples of neighbouring established ideas include invariants under group action, equivariant maps, quotient spaces, gauge-invariant observables, nuisance-parameter elimination, sufficient statistics, paired/differential measurements, and representation-independent observables.

MKUFT does not claim those ideas individually. The bounded contribution of this note is their explicit placement inside the Future-Sufficient Address repair geometry:

```text
restore down
promote up
rotate sideways
```

with the same preserve/reopen, strongest-fair-null, prospective, and no-untyped-inheritance burdens already present in the stack.

## 10. Falsification / contraction

The sideways branch contracts if:

- matched prospective tests show no advantage over direct restoration or native methods;
- the nuisance family cannot be declared independently enough to prevent post-hoc fitting;
- transformed queries repeatedly lose target information;
- ordinary domain-native sufficient statistics already own the entire useful result with no additional organisational value;
- the three-way repair language adds cognitive overhead without changing prediction, intervention, restoration cost, or scientific discrimination.

In those cases the useful content should be absorbed into the native owner and the MKUFT-specific claim reduced accordingly.
