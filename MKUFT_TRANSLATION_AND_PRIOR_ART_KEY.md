# MKUFT Translation and Prior-Art Key

**Purpose:** help an outside reader translate recurring MKUFT terms without flattening them into the nearest familiar concept or treating an unfamiliar name as evidence of novelty.

**Status:** reader-facing interface only. This file does not own the scientific claims, equations, novelty decisions, or prior-art record. The technical modules remain authoritative for their own objects. For the deeper positioning map, use [MKUFT Science Convergence and Novelty Map](SCIENCE_CONVERGENCE_AND_NOVELTY_MAP.md).

## The rule for using this key

This is **not** a dictionary of one-to-one scientific equivalents.

Two opposite errors are common:

```text
familiar components exist
→ therefore MKUFT is only renaming them
```

and

```text
no single textbook name exists for the whole combination
→ therefore the combination is novel
```

Neither inference is valid by itself.

For every MKUFT handle, ask instead:

```text
plain object
→ closest established scientific neighbours
→ what those neighbours already own
→ exact residual composition / operation MKUFT is claiming
→ what evidence would show that residual does useful work
→ what result reduces or removes the need for the separate handle
```

> **Similarity does not establish equivalence. Lack of a single established name does not establish novelty. A separate MKUFT handle earns retention only when its exact composition or operation can be stated after native ownership is subtracted and that residual does useful work.**

The examples below are deliberately short. They are translation aids, not substitutes for the technical papers.

## Layer Before Law

**Plain object:** before choosing or applying a law, first establish what object is being modelled, at what scale and boundary, with what state variables and admissible transitions.

**Closest established neighbours:** model specification, system identification, state-space selection, boundary-condition discipline, coarse-graining, effective theories, multiscale modelling.

**Already owned by established science:** scientists already choose variables, scales, domains and boundary conditions; effective descriptions and coarse-grained states are standard.

**MKUFT residual claim:** the ordering itself is promoted to a standing cross-domain decision rule: object/address sufficiency must be tested before law ownership is granted, and the model must reopen when the chosen address stops carrying the target prediction.

**Not equivalent to:** the claim that physical laws are merely software-like runtime outputs of an independently proven information layer. That stronger ontology is not required to use or test Layer Before Law.

**Example:** two neural systems can show matched present activity yet diverge because a recent-history variable was omitted. The law/model may be fine; the state handed to it was incomplete.

**Reduction / kill:** if ordinary model specification and state-selection practice already produces the same decisions, predictions and failure localisation with equal or better clarity, the separate MKUFT ordering has not earned additional scientific necessity.

Read: [Layer Before Law](docs/26_LAYER_BEFORE_LAW_MKUFT_QUANTUM_GRAVITY_REFRAMING.md).

## Address / Addressing / Readdressing

**Plain object:** the declared representation from which the current question is being asked: object identity, scale, boundary, retained state, context/history where needed, and evidence/registration position.

**Closest established neighbours:** state representation, sufficient state, coarse-grained variables, model context, conditioning variables, coordinate charts, abstraction level, multiscale state descriptions.

**Already owned by established science:** none of those ingredients is new merely because MKUFT groups them under one handle.

**MKUFT residual claim:** one explicit object carries the bookkeeping needed to decide when a representation is sufficient for a target property and when evidence forces movement upward, downward or multiscale without silently changing the question.

**Example:** a heart-level state can be sufficient for one rhythm prediction but insufficient for an ion-channel prediction. The object is not discarded; the address changes for the property being asked about.

**Reduction / kill:** if the address handle adds no operational protection against state omission, scale bleed, context loss or false equivalence beyond the native field's ordinary representation discipline, use the native representation instead.

## SIPO — Substrate, Information, Physical, Observer

**Plain object:** four typed modelling addresses used to stop different kinds of statement from silently impersonating one another.

**Closest established neighbours:** typed state spaces, latent/observed-variable distinctions, information-theoretic descriptions, physical state descriptions, measurement/registration models, source-to-observation pipelines.

**Already owned by established science:** latent variables, information structures, physical variables and measurement contexts are not MKUFT inventions.

**MKUFT residual claim:** the S/I/P/O separation is used as an anti-flattening architecture: a relation stated at one address does not become a law, mechanism or evidence at another address without an explicit bridge.

**Not equivalent to:** four spatial dimensions, four new physical fields, or proof that an independent physical information/substrate layer exists.

**Example:** an informational relation can organise a model without thereby becoming a physical force. A physical claim still needs a carrier, observable consequence, units where applicable and a falsifier.

**Reduction / kill:** if SIPO typing does not prevent invalid inheritance or improve model/equation hygiene beyond simpler native distinctions, it is decorative bookkeeping.

Read: [Typed Traversal and Equation Hygiene](docs/27_TYPED_TRAVERSAL_AND_EQUATION_HYGIENE.md) and [SIPO Capstone](docs/33_SIPO_CAPSTONE_CONSTRAINT_CONDITIONED_ADDRESSED_UPDATE_LAW.md).

## Typed Traversal

**Plain object:** move through a chain of states or representations while keeping the type of each object and each map explicit.

**Closest established neighbours:** typed mathematics, domain/codomain discipline, dimensional analysis, state-space modelling, graph traversal, composable maps, interface/type checking.

**Already owned by established science:** state-space movement, graph traversal, typed maps and dimensional consistency are established ideas.

**MKUFT residual claim:** the specific hygiene rule that physical, informational, observer-positioned and other abstract spaces may constrain one another without being flattened into one geometry; every cross-space move must declare what maps from where to where and what would make the bridge fail.

**Not equivalent to:** simply "moving through a state space with strict rules." That captures part of the object but misses the anti-flattening and cross-address burden that motivates the MKUFT handle.

**Example:** `C_IP : X_I → X_P` names a proposed information-to-physical mapping task. Writing the arrow does not establish the physical coupling.

**Reduction / kill:** if ordinary type discipline and dimensional analysis catch every error the MKUFT traversal rule is meant to catch, the special handle has no additional scientific load.

Read: [Typed Traversal and Equation Hygiene](docs/27_TYPED_TRAVERSAL_AND_EQUATION_HYGIENE.md).

## Strongest Fair Null

**Plain object:** do not let a target claim win against an artificially weak opponent. Construct the strongest serious admissible non-target comparison that preserves the relevant information and resources, then ask what survives.

**Closest established neighbours:** composite-null design, least-favourable configurations in particular statistical settings, active controls, strong/SOTA baselines, adversarial model comparison, ablation controls, sensitivity analysis, model selection and prior-art subtraction.

**Already owned by established science:** null hypotheses, active controls, strong baselines, adversarial comparison and least-favourable statistical constructions all have established histories. MKUFT does **not** claim lexical or generic methodological priority for them.

**MKUFT residual claim:** a standing cross-domain comparison rule that can combine, as appropriate to the actual claim, strongest component-alone conditions, lawful independent combinations, one-way assistance, full-history replay/transfer, alternative pairings, relation scrambling and native-domain competitors under a matched resource envelope.

**Not equivalent to:** one universal "least favourable null hypothesis." Least-favourable configurations are one neighbour; the MKUFT object can be a broader preregistered family of serious controls whose exact members depend on the claim being tested.

**Example:** if a live human–AI pair is claimed to gain from reciprocal history, a fair null cannot be a reset AI denied the history. A competent full-history replay condition must be allowed to try to recover the gain.

**Reduction / kill:** if standard best-practice comparator design already generates the same serious control family and reaches the same scientific decisions without the MKUFT handle, keep the native methodology. If the focal effect disappears against the strongest admissible control, the stronger target claim fails.

Read: [Strongest Fair Null and Relational Specificity](docs/24B_STRONGEST_FAIR_NULL_AND_RELATIONAL_SPECIFICITY.md).

## Relational Closure

**Plain object:** the relations that make an organised whole remain the same functional kind of whole are sufficiently realised to support that organisation at the declared scope.

**Closest established neighbours:** organisational/constraint closure, autonomy, dynamical closure, equivalence classes, coarse-graining, emergent organisation, network/relational descriptions.

**Already owned by established science:** closure and emergent organisation have substantial prior art.

**MKUFT residual claim:** closure is kept separate from the stronger question of whether the whole-level variables are sufficient to carry a law for a particular property. A whole may remain real and organised while law sufficiency fails for one target.

**Example:** a heart remains a heart even if a heart-level state is insufficient to predict one microscopic electrical failure.

**Reduction / kill:** if ordinary closure/coarse-graining methods already make the same separation and predictions, MKUFT has not added a new mechanism; at most it has supplied synthesis or translation.

Read: [Relational Closure, Law Descent, and Bidirectional Readdressing](docs/33S2_RELATIONAL_CLOSURE_LAW_DESCENT_AND_BIDIRECTIONAL_READDRESSING.md).

## Law Descent

**Plain object:** when is a higher-level description sufficient to own an effective law for a declared property and regime?

**Closest established neighbours:** lumpability, coarse-graining, sufficient statistics, effective theories, causal abstraction, model reduction, Mori–Zwanzig/history repair, property- or goal-oriented reduction.

**Already owned by established science:** higher-level effective laws, reduction and coarse-grained predictive sufficiency are established topics.

**MKUFT residual claim:** a property-specific decision architecture: the higher level may carry the law only where sufficiency is demonstrated, and it must surrender or share that ownership when matched lower states inside one higher-level class produce materially different target futures.

**Example:** if two microstates are represented as the same macrostate but produce different relevant macro futures, the macro description has not earned a closed law for that property.

**Reduction / kill:** if established lumpability/abstraction/reduction machinery gives the same sufficiency test, reopening rule and practical result, the separate MKUFT law-descent handle reduces to synthesis.

Read: [Relational Closure, Law Descent, and Bidirectional Readdressing](docs/33S2_RELATIONAL_CLOSURE_LAW_DESCENT_AND_BIDIRECTIONAL_READDRESSING.md) and [Law Descent and Recoverability Novelty Audit](docs/33A_LAW_DESCENT_AND_RECOVERABILITY_NOVELTY_AUDIT.md).

## Address Sufficiency / Predictive Closure

**Plain object:** does the state the model currently keeps contain enough information to distinguish the future quantity the task cares about?

**Closest established neighbours:** Markov/state sufficiency, predictive-state representations, hidden-state models, sufficient statistics, state augmentation, observability and system identification.

**Already owned by established science:** hidden state and predictive sufficiency are not new concepts.

**MKUFT residual claim:** place the sufficiency question explicitly inside the address/law-ownership chain so that future divergence becomes a controlled reason to reopen the state rather than an excuse for post-hoc complexity.

**Example:** two systems the model calls equivalent now diverge later beyond the declared tolerance; the current representation is insufficient even before the missing variable has been identified.

**Reduction / kill:** if ordinary stochastic, hidden-state or predictive-state modelling explains the split under the declared uncertainty, no stronger MKUFT claim is needed.

Read: [Address Sufficiency and Predictive Closure](docs/33S4_ADDRESS_SUFFICIENCY_PREDICTIVE_CLOSURE_AND_REACHABLE_FUTURE_GEOMETRY.md).

## Rate-Conditioned Addressing

**Plain object:** timing, rate, phase, dwell or bounded history may have to become part of the state when the future depends on them.

**Closest established neighbours:** non-Markovian dynamics, hysteresis, path dependence, relaxation times, time-dependent control, forcing history, phase-dependent systems.

**Already owned by established science:** rate dependence, memory and hysteresis are established phenomena.

**MKUFT residual claim:** timing/history is recruited only after a present-state description fails a prospective sufficiency test; it is not automatically promoted to a new coordinate or mechanism.

**Example:** two systems traverse the same nominal path but spend different times near a critical regime and therefore leave with different internal states.

**Reduction / kill:** if ordinary physical state plus forcing/history already predicts the result, do not create a separate MKUFT mechanism.

Read: [Rate-Conditioned Addressing](docs/33S5_RATE_CONDITIONED_ADDRESSING_TIME_PARAMETERISED_TRAVERSAL_AND_ADAPTIVE_REORGANISATION.md).

## Recoverability / Addressed Admissible Futures

**Plain object:** present performance is not the same as still having an allowed route to a desired future or back to a target after perturbation.

**Closest established neighbours:** reachability, viability theory, resilience, controllability, basin structure, safe sets, restorative control and robustness.

**Already owned by established science:** reachability, viability and resilience have substantial mature literatures.

**MKUFT residual claim:** explicitly separate local performance, whole-level closure, law sufficiency and target-relative restorative reachability, then ask how much viable future route structure remains at the current address.

**Example:** two systems function equally well today, but only one retains a lawful recovery route after the next perturbation.

**Reduction / kill:** if standard reachability/viability/control methods capture the same distinction and prediction with equal or better clarity, the MKUFT contribution is synthesis/translation rather than new mechanism.

Read: [Addressed Admissible Futures](docs/33S6_ADDRESSED_ADMISSIBLE_FUTURES_RESTORATIVE_REACHABILITY_AND_LOAD_BEARING_FUTURE_GEOMETRY.md).

## Future-Splitting State Recruitment (FSSR)

**Plain object:** deliberately challenge states the current model treats as equivalent; if their futures split, identify the smallest defensible missing state variable and test it prospectively.

**Closest established neighbours:** perturbation experiments, system identification, hidden-state estimation, predictive-state sufficiency, intervention/ablation, state augmentation and mechanism localisation.

**Already owned by established science:** perturbation, hidden-state modelling and state augmentation are standard families.

**MKUFT residual claim:** the particular assay ordering: matched present representation → deliberately different histories where appropriate → lawful future challenge → measured split → minimal state recruitment → fresh-data prediction → removal/restoration deformation test.

**Example:** matched current neural activity from different recent histories; test whether an apparent connectivity edge disappears and held-out prediction improves after adding the smallest biologically defensible retained-state variable.

**Reduction / kill:** if stronger ordinary measurement, noise control or conventional hidden-state estimation removes the split, the stronger FSSR mechanism-localisation language is not earned. If the recruited variable adds nothing on fresh cases, it earns nothing in that system.

Read: [Future-Splitting State Recruitment](docs/33S7_FUTURE_SPLITTING_STATE_RECRUITMENT_STATE_ADEQUACY_AND_PROSPECTIVE_MECHANISM_LOCALISATION.md).

## LUCY — Local Unified Coherence Yield

**Plain object:** a proposed threshold at which an addressed relational configuration becomes consequential at the next declared layer. In a physical I→P branch, the claim is that a defined relational configuration changes physical transition weighting, admissibility, boundary condition or effective state beyond the adequate physical baseline.

**Closest established neighbours:** critical phenomena, phase transitions, order parameters, bifurcations, Landau–Ginzburg threshold models, metastability/domain formation and scalarisation-type threshold effects.

**Already owned by established science:** thresholded state changes, critical surfaces, domains and emergent-gravity programmes all have extensive prior art.

**MKUFT residual claim:** the typed crossing architecture and its declared downstream branch structure, with the physical burden placed on a prospective residual beyond conventional explanations. `LUCY-1` and `LUCY-2` are possible downstream interface/domain morphologies, not the definition of LUCY itself.

**Not equivalent to:** signal-to-noise ratio. A ratio may appear inside one candidate index, but the canonical LUCY object is the thresholded addressed crossing and its typed consequence.

**Example:** a physical implementation would have to specify control parameters, an order parameter/critical surface, carrier into P, ordinary limit, observables and a preregistered threshold before claiming a LUCY crossing.

**Reduction / kill:** if the variable cannot be operationalised, the threshold is fitted after the event, ordinary critical/physical models predict equally well, or no measurable residual remains beyond the adequate physical baseline, the physical LUCY claim contracts or reduces.

Read: [LUCY Threshold Geometry and Relational Closure](docs/30_LUCY_THRESHOLD_GEOMETRY_AND_RELATIONAL_CLOSURE.md).

## ATLD / ATLD 2

**Plain object:** an AI/methods evaluation branch asking whether typed relational architecture itself carries measurable long-horizon reasoning load under matched controls.

**Closest established neighbours:** ablation studies, memory/retrieval evaluation, agent architectures, graph/relational representations, longitudinal benchmarking, matched-control experimental design and model comparison.

**Already owned by established science:** none of those evaluation families is new merely because ATLD combines them.

**MKUFT residual claim:** use a structured set of typed relationship/readout coordinates plus matched deformation controls to ask not merely whether output is good, but which relational function changes when the architecture is removed, scrambled, replayed or substituted.

**Current status:** ATLD 2 is an executable methods/evaluation protocol with a bounded exploratory 15-case execution pilot. That pilot does not establish confirmatory superiority or completed validation of the candidate residual coordinates.

**Reduction / kill:** if flat, replayed, scrambled, isolated or otherwise simpler matched conditions perform equally well, the stronger architecture claim contracts. Self-application is not independent certification.

Read: [ATLD 2 v2.0](papers/2026-08-23_ATLD2_RESIDUAL_COORDINATE_IDENTIFICATION_v2.0.md).

## Preserve / Reopen

**Plain object:** keep a representation while it remains sufficient for the declared task; reopen hidden detail when a controlled test shows that the compression has lost a load-bearing distinction.

**Closest established neighbours:** adaptive model refinement, coarse-graining/reconstruction, abstraction refinement, model selection, state augmentation and error-driven representation change.

**Already owned by established science:** preserving useful abstractions and refining failed ones is not a new scientific idea by itself.

**MKUFT residual claim:** a cross-domain decision contract tying preservation/reopening to typed failure conditions, provenance/descent and the specific property/future for which sufficiency was tested rather than to intuition after the result.

**Example:** the Bell/CHSH tetrahedral calibration preserved the exact formal correspondence but reopened the novelty claim when the purported independent physical residual reduced to known CHSH structure.

**Reduction / kill:** if the rule supplies no cleaner prospective decision, no better failure localisation and no transfer advantage beyond ordinary refinement practice, it is only a useful explanatory shorthand.

Read: [Cross-Domain Compositional Schema v0.4](papers/2026-08-29_CROSS_DOMAIN_COMPOSITIONAL_SCHEMA_v0.4.md) and [Bell/CHSH Calibration](docs/28A_CROSS_DOMAIN_COMPOSITIONAL_SCHEMA_BELL_CHSH_CALIBRATION.md).

## What this key is allowed to conclude

An entry can end in several legitimate states:

- **native term preferred** — MKUFT adds nothing useful; use the established name;
- **translation/synthesis** — the assembly is useful but does not yet establish a distinct scientific object;
- **candidate operational residual** — a specific procedure or discriminator remains after prior-art subtraction and is prospectively testable;
- **candidate physical residual** — only where a physical carrier, units/observables, baseline and discriminating result are supplied;
- **null/reduction** — the purported residual disappears under the stronger native account.

No entry is promoted merely because it lacks a one-word external synonym.

## Reader contract

> **Do not ask whether an MKUFT word sounds new. Ask what established science already owns, what exact operation remains after subtraction, and what result would make that remaining operation unnecessary.**

This key should stay smaller than the science it points to. Add a term only when recurring reader confusion shows that the translation burden is real.
